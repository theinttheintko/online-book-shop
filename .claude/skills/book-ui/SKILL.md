# Skill: Bookstore UI Standards
This skill enforces consistent design across all bookstore components.

## Component Guidelines
- **Book Cards**: Must display cover, title, author, rating, and price. 
- **Layout**: Use CSS Grid/Flexbox for the "Latest Items" section to ensure responsiveness.
- **Styling**: Ensure consistent padding, font-sizes, and color usage for price tags and titles.
- **State**: Ensure loading states are displayed while fetching books.
