# Skill: Bookstore UI Standards

This skill keeps the bookstore design clean and easy to use.

## Design Rules
- **Cards**: Each book card must show the cover, title, author, and price clearly.
- **Layout**: Use grid layouts so the website looks good on phones, tablets, and computers.
- **Colors & Spacing**: Use clean spacing (16px) and consistent colors (#333333 for text) throughout the site.
- **Loading**: Show a simple loading state when fetching book data so the user isn't looking at a blank screen.
- **Buttons**: All buttons should have a smooth 0.3s hover effect.

## Why this is important
This file is the main guide for my AI agent. It makes sure that every time the AI builds or fixes a component, it keeps the design consistent. By following these simple rules, I prevent the design from getting messy, keep the code easy to read, and ensure the website always looks professional.
